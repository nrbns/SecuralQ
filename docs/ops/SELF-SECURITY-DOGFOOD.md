# Self-security dogfood report

Generated by `python scripts/dogfood_security_report.py --write-docs` (and
`GET /api/admin/self-security/dogfood`).

## Scope

- **In-product:** Bandit SAST against `app/` via `app/self_security.py`.
- **CI:** `.github/workflows/security-scan.yml` — pip-audit, Bandit, Semgrep,
  Gitleaks, Trivy, Checkov, CodeQL, SBOM, ZAP baseline.

## Honesty

This is a **lab-production** dogfood snapshot. It does not invent container CVE
counts when Trivy is absent from the local machine. It is **not** a full
pentest or FedRAMP evidence package.

Refresh locally:

```bash
python scripts/dogfood_security_report.py --write-docs
```

Or via API (auth + `audit.read`):

```http
GET /api/admin/self-security/dogfood?refresh=true
```
